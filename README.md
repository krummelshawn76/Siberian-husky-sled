Siberian Husky Saga

Welcome to Siberian Husky Saga, a multi-edition browser game where you play as Spartan, a Siberian Husky on a journey for power, gems, and legendary companions.

This repo contains three separate game editions, each with its own stylesheet and progression rules. All editions share the same core game engine (game.js).


---

🎮 Game Editions

1. Fresh Bait Edition (Free)

Basic progression

Spartan only

Gems earned through missions

No premium features

Max Level: 10


2. Hunter Edition (Enhanced)

Auto-run missions

Premium gem shop through Stripe Payment Link

Upgraded progression curve

Max Level: 30


3. GOD Saga Edition (Ultimate)

Auto-run

Premium gem shop via Stripe

Highest progression

Unlock Trigger (Yellow Lab companion) at max level

Max Level: 99



---

💎 Currency System – Gems
